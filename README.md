# VulkanModHDR (Refactor Fork)

This repository is a **small, upstream-intended refactor fork** of [VulkanMod](https://github.com/xCollateral/VulkanMod).

## Intent

- Keep the original VulkanMod work attributed to its original authors.
- Maintain only targeted refactor changes in this fork.
- Make those refactor changes easy to review and upstream.
- Avoid creating ownership confusion around upstream VulkanMod code.

## Ownership and Attribution

- **I do not claim ownership of VulkanMod's existing codebase.**
- Copyright for pre-existing VulkanMod code remains with VulkanMod's original contributors.
- This fork only claims authorship over the **new, minimal refactor deltas** introduced here.

## Legal Bounds

This repository distributes and modifies code from VulkanMod. As such:

- Upstream/inherited code remains under its original licensing terms.
- Refactor contributions in this fork are licensed compatibly so they can be upstreamed.
- You must preserve attribution and license notices when redistributing.

See the [LICENSE](./LICENSE) file for full terms and the fork-specific licensing notice.

## Upstream-First Policy

If a refactor is accepted upstream, upstream should be treated as the canonical source for that change whenever practical.

## Support

For original VulkanMod support, features, and releases, refer to the upstream project:
- https://github.com/xCollateral/VulkanMod
